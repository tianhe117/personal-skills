# Personal Skills

我维护的 Codex skills，每个 skill 一个目录。

| Skill | 用途 |
| --- | --- |
| [python-web-docker](python-web-docker/SKILL.md) | 为 Python Web 工具配置 Docker Compose 部署、源码挂载和本地覆盖配置。 |

使用时，将所需 skill 的整个目录复制到个人 Codex skills 目录（`$CODEX_HOME/skills`，默认 `~/.codex/skills`），然后用 `$python-web-docker` 这样的名称调用。

在本仓库修改和提交，更新后再同步本地安装。示例只放占位值。
